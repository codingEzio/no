## 概要

選んだドメインへのアクセスを、画面全体の NO ✋ で止めます。Chrome ソース版0.99.1は既存の拡張IDと設定を保持します。

## 使い方

Chrome の「パッケージ化されていない拡張機能を読み込む」で extension_chrome/ を選択。ポップアップにドメインまたは HTTP(S) URL を追加して有効化し、保存します。サイトアクセスを許可する必要があります。保存・適用済みと適用待ちを区別し、再保存で再試行できます。更新時に公開鍵や既存設定を消さないでください。

## プラットフォーム制限

現在のパッケージ対象は Chrome。デスクトップ Safari ソースは 0.99.0 のままで、popup CSS の代替フォントをシステムのサンセリフに合わせました。完全な開発ソースには以前の文字設定スクリプトと既定値が残り、保存済みのフォント設定は移行しません。完全な Safari 同期は未確認で、選択ソースには独立したネイティブ host 生成用のアイコン入力がありません。権限、実際のリダイレクト、Service Worker フォールバック、性能は別途検証が必要です。Firefox 配布は停止中。Chrome ビルドは他ブラウザーの動作証明ではありません。

## ソースとビルド

macOS で Deno 2.x と Git を用意して、このリポジトリで次を実行します。検査は合成したローカル例を使います。ビルドは無視対象の Local/candidates に候補を作り、正確なバイト列を読み戻します。拡張機能の導入やブラウザー起動は行いません。本機の検証では非公開デフォルトを読み取る場合がありますが、通常および公開パッケージには含まれません。一致する完成済み候補は検証して再利用し、その他の候補は保持します。通常の検査は固定済みローカル依存を使い、隣のソースディレクトリは不要です。

```sh
deno task check
deno task build
```

確認済みのファイルを名前指定でステージし、deno task public:check と deno task public:prepare を実行します。public-source.json が正確な Git index 入力を選び、個人の運用記録・設定・Git 履歴は除外します。候補は不変で、再実行は照合のみ。不一致を上書きしません。限定的なパターン検査は履歴や秘密の完全検査ではありません。準備によって受信先・データ・ブラウザー設定は変わりません。

## 任意の非公開デフォルト

`extension_chrome/` を直接読み込む場合、Git 管理外の `extension_chrome/private-defaults.json` を `{"domains":["example.com"]}` のように作成し、拡張機能を再読み込みします。ファイルはデータであり実行されず、ソースの書き出しや Chrome、Safari、Firefox のパッケージにも含まれません。保存済み設定が優先されます。設定がない場合は既存の動的ルールを優先して保持します。どちらもない場合、ファイルがないか読めなければ空のリストを使い、不正な JSON はエラーになります。Safari と Firefox は使用しません。
