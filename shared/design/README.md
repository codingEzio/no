# Shared popup reference

`popup.css` and `contract.json` describe a reusable popup baseline.
`reference.html` is a nonfunctional local layout reference; it does not use
extension APIs or write data. Product-specific styles and behavior remain in
their respective source directories.

Bundled font sources, versions and licenses are recorded with the fonts in
`fonts/` and their provenance and notice files. Geist and Geist Mono derive
from vercel/geist-font v1.7.2, revision
`a73329da8fc62afc917f796555202e4997f79b7c`, under SIL OFL 1.1. Doto assets
retain their original OFL notices and derivation metadata.
