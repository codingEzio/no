# Extension icon styles

The selected toolbar artwork uses `nothing-signal-v1 / universal`. Source SVGs
and prepared PNGs are inventoried in `../icon-styles.json`. Nothing is a design
inspiration, not an affiliation; the geometry is original.

The review assets were rendered with librsvg `rsvg-convert` 2.63.2
(LGPL-2.1-or-later). `index.html` is a local visual comparison and uses no
network requests. Chrome action icon guidance: https://developer.chrome.com/docs/extensions/reference/api/action
