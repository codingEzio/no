## 개요

선택한 도메인 방문을 전체 창 NO ✋ 화면으로 막습니다. Chrome 소스0.99.1은 기존 확장 ID와 설정을 유지합니다.

## 사용

Chrome의 “압축해제된 확장 프로그램 로드”에서 extension_chrome/을 선택합니다. 팝업에 도메인 또는 HTTP(S) URL을 추가하고 항목을 켠 뒤 저장하세요. 사이트 접근 권한이 있어야 차단됩니다. 저장·적용 완료와 규칙 적용 대기를 구분하며 다시 저장하여 재시도할 수 있습니다. 업데이트를 위해 공개 키나 기존 설정을 지우지 마세요.

## 플랫폼 제한

현재 패키징 대상은 Chrome입니다. 데스크톱 Safari 소스는 0.99.0을 유지하며 popup CSS의 대체 글꼴을 시스템 산세리프로 맞췄습니다. 전체 개발 소스에는 이전 글꼴 스크립트와 기본 메타데이터가 남아 있으며 저장된 글꼴 선택은 이전하지 않습니다. 전체 Safari 동기화는 검증하지 않았고 선택 소스에는 독립 네이티브 host 생성용 아이콘 입력이 없습니다. 사이트 권한, 실제 리디렉션, Service Worker 대체 경로와 성능은 별도 검증이 필요합니다. Firefox 배포는 중단 상태이며 Chrome 빌드가 다른 브라우저 동작을 증명하지 않습니다.

## 소스와 빌드

macOS에서 Deno 2.x와 Git을 설치하고 저장소에서 아래 명령을 실행합니다. 검사는 합성 로컬 예제를 사용합니다. 빌드는 무시된 Local/candidates에 후보를 만들고 정확한 바이트를 읽어 확인합니다. 확장을 설치하거나 브라우저를 열거나 개인 설정을 읽지 않습니다. 일반 검사는 고정된 로컬 의존성을 사용하며 형제 소스 디렉터리가 필요하지 않습니다.

```sh
deno task check
deno task build
```

## 개인정보와 소스 검토

검토한 파일을 이름으로 지정하여 스테이징한 뒤 deno task public:check와 deno task public:prepare를 실행합니다. public-source.json은 정확한 Git index 입력을 선택하고 개인 운영 기록, 설정 및 Git 기록은 제외합니다. 후보는 변경할 수 없으며 재실행은 일치 여부만 확인하고 불일치를 덮어쓰지 않습니다. 제한된 패턴 검사는 전체 기록이나 모든 비밀의 검증이 아닙니다. 준비 과정은 수신 대상, 데이터 또는 브라우저 설정을 바꾸지 않습니다.
