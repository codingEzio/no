# Original Cubic 11 font

The original official WOFF2 is redistributed unchanged, with its complete original OFL and inherited Cubic / JF Dot / M+ notices in Cubic11-OFL.txt. Cubic and 俐方體 are upstream reserved names. No glyphs, metrics, names or coverage are modified, merged or subset here. CSS alias Extension Cubic 11 identifies the embedded source without a local() lookup.
